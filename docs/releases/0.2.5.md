# Release 0.2.5

Date: 2026-08-31

## Summary

Releases now publish authored release notes with validated BRAT assets, while
the semver tag trigger accepts the repository's full numeric release-tag format.

## Changed

- GitHub Releases now use the version-specific authored notes from
  `docs/releases/<X.Y.Z>.md` as their release body.
- Release validation now checks the release notes, plugin metadata, and
  non-empty root assets before packaging the BRAT ZIP.

## Fixed

- Corrected the GitHub Actions semver tag trigger patterns so valid release tags
  with multi-digit numeric components are selected and incomplete tags are not.

## Documentation

- Documented the authored release-notes format, validation requirements, asset
  contract, and publication verification steps in the README and release guides.
