# Release 0.2.4

Date: 2026-08-31

## Summary

Restored the location picker suggestions and made vault-derived location usage
refresh safely after note metadata changes.

## Fixed

- Restored the visible location suggestions below the picker input.
- Rebuilt suggestions on every keystroke while preserving substring matching,
  ranking, keyboard navigation, and mouse selection.
- Refreshed vault-derived location usage before opening the picker.
- Waited for the corresponding metadata-cache update after note modifications;
  an unresolved cache no longer erases the previous usage snapshot.

## Documentation

- Documented the picker UX, usage synchronization, build/test requirements, and
  release asset contract.
