# Release 0.2.7

Date: 2026-09-02

## Summary

Shortcut badges are hidden outside the focused suggestion block. When the suggestion block is focused, badges use a compact plain superscript-like upper-right style without oval decoration or layout reflow. Existing Tab and number shortcut behavior is preserved.

## Changed

- Shortcut badges now stay hidden unless focus is inside the suggestion block.
- Focused suggestion badges are compact plain upper-right labels that do not change layout.
- Existing Tab navigation and number shortcut behavior remains unchanged.
