# Release 0.2.6

Date: 2026-09-01

## Summary

The location picker now makes its keyboard shortcuts visible and provides
predictable focus traversal, making suggestion selection faster without a
mouse.

## Added

- Visible `1` through `5` shortcut badges identify the currently displayed
  suggestions.
- A focused suggestion can be selected with its displayed number.

## Changed

- Forward `Tab` moves from the input to the first visible suggestion and then
  to `Submit`; when there are no results, it moves directly to `Submit`.
- Arrow navigation keeps every visible suggestion focusable through roving
  `tabindex`, while number shortcuts use the current visible ordering and
  ignore modified digits and digits typed in the input.

## Documentation

- Documented the picker keyboard behavior and added regression coverage for
  shortcut badges, Tab/focus traversal, numeric selection, and ignored digit
  cases.
